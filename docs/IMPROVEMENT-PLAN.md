## งานค้าง

### [deferred] A1b อนุมัติเฉพาะบางรายการในออเดอร์
**เลื่อนออกจาก v1 โดยการตัดสินใจของผู้ใช้ (28 ส.ค. 2569)** — สำรวจโค้ดจริงแล้วพบว่าเป็นงานรื้อ ไม่ใช่งานเติม

เหตุผลที่เลื่อน (จดไว้กันรอบหน้าต้องหาใหม่):
1. **claim เป็นระดับออเดอร์** — `lib/po/approve-with-split.ts` ทำ compare-and-set ทั้งแถว Order
   เป็นทั้ง concurrency guard + `decidedAt` + "บรรทัดไหนได้ออก PO" ในการเขียนครั้งเดียว ·
   status gate ที่ `app/api/orders/route.ts` บล็อกทุก action เมื่อออเดอร์ไม่ใช่ `pending_approval`
   → อนุมัติรอบสองจะโดน 409 ทันที
2. **ไม่มีสถานะระดับบรรทัด** — migration เพิ่มง่าย แต่มี ~8-10 จุดต้อง filter ตาม
   (approve mapper, `SplittableItem`, order-history, การหักยอด in-flight, po-split-panel)
3. **โปรกลุ่ม pooled = กับดักราคา** — อนุมัติ 2 จาก 4 บรรทัดของกลุ่ม บรรทัดที่รอดยังถือ snapshot
   `c4PromoGroupMembers`/`c4PooledQty`/`c4DiscountBaht` ของกลุ่มเต็มที่ไม่จริงแล้ว
   → **ราคาผิดบนเอกสารที่ส่งฝ่ายจัดซื้อ** · `validatePoSplit` มีแต่กฎ "ห้ามแยกกลุ่มข้าม PO"
   ยังไม่มีกฎ "กลุ่มไม่ครบ"
4. **`@@unique([orderId, groupKey])`** บังคับให้ต้องตัดสินใจก่อนว่า "wave เดียว ที่เหลือตกไป"
   หรือ "หลาย wave" (แต่ละ wave เผาเลข `PoSequence` ใบใหม่)

**ทำไปแล้ว 2 ชิ้นที่ปิดความเจ็บเฉพาะหน้าได้ (28 ส.ค.)** — ดู changelog รอบ 5

- เทสต์ 305 เคส / 27 ไฟล์ · ยังไม่มีเทสต์ระดับ API route / component (ตั้งใจ) แต่เปิดข้อยกเว้นให้
  ตรรกะระดับ lib ที่เป็นทรานแซกชันจริงใช้ SQLite ชั่วคราวได้แล้ว (`tests/**/*.db.test.ts`)
- **⏳ รอฝั่งผู้ใช้:** ตรวจ `.env` ของ production ว่ามี `NEXTAUTH_SECRET` ตัวจริง (≥32 ตัว) และตั้ง
  `SENDER_EMAIL` + `ALERT_EMAIL` ครบทั้งคู่ แล้วยิงอีเมลแจ้งเตือนทดสอบ 1 ฉบับ
- **⏳ รอฝั่งผู้ใช้:** ซ้อมกู้คืนฐานข้อมูลจาก backup 1 ครั้งก่อนเปิดใช้จริง
- **⚠️ ยังไม่ได้ตรวจด้วยตาบนเครื่องจริง:** จอแคบ `<1280px` — รอบ 6 ตรวจผ่าน iframe 390px แล้ว
  (พบและแก้เรื่องแถบแท็บฝั่งเซลส์ล้นจอ) แต่ยังไม่ได้เปิดบนมือถือจริง
- **ค้างไว้รอผู้ใช้ตัดสินใจ (จากการทดสอบรอบ 5–6):** `CustomerMobileNav` เป็นโค้ดที่ไม่ถูกเรียกใช้เลย
  ทั้งที่หน้าร้านยังเว้น `pb-20`/`pb-16` ไว้ให้แถบที่ไม่เคยแสดง — ต้องเลือกว่าจะเปิดใช้หรือลบทิ้ง ·
  ช่องวันที่แสดงรูปแบบ `mm/dd/yyyy` ตาม locale ของเบราว์เซอร์บน UI ภาษาไทย (แก้ได้ต้องเขียน
  date picker เอง) · `CvdFlagCell` ต่ำกว่า 1280px สื่อด้วยสีอย่างเดียว
