## การเข้าสู่ระบบ

หน้าแรกของระบบจะให้เลือกบทบาทผู้ใช้งาน

### ร้านค้าและคลัง VDA — ใช้อีเมลและรหัสผ่าน

การใช้งานครั้งแรก ระบบจะนำผู้ใช้ไปตามขั้นตอนโดยอัตโนมัติ เพียงกรอกอีเมลแล้วดำเนินการต่อ

```
กรอกอีเมล
   │
   ├─ ยังไม่มีบัญชี          → เลือก VDA ของร้าน → ส่งคำขอ → รอผู้ดูแลระบบอนุมัติ
   ├─ ส่งคำขอแล้ว            → ระบบแสดงสถานะ "รอผู้ดูแลยืนยันสิทธิ"
   ├─ อนุมัติแล้วแต่ยังไม่ตั้งรหัส → กำหนดรหัสผ่านครั้งแรก (อย่างน้อย 8 ตัวอักษร)
   └─ มีบัญชีครบถ้วนแล้ว      → กรอกรหัสผ่าน → เข้าใช้งาน
```

**กรณีลืมรหัสผ่าน** เลือก "ขอรีเซ็ตรหัสผ่าน" ที่หน้าเข้าสู่ระบบ แล้วแจ้งผู้ดูแลระบบ
เมื่อผู้ดูแลดำเนินการแล้ว ผู้ใช้จะกำหนดรหัสผ่านใหม่ในการเข้าสู่ระบบครั้งถัดไป

> **เดิมสามารถเข้าใช้งานโดยเลือกรหัส VDA เท่านั้น ไม่ต้องใช้รหัสผ่าน ปัจจุบันยกเลิกวิธีดังกล่าวแล้ว**
> เนื่องจากระบบเปิดให้เข้าถึงผ่านอินเทอร์เน็ต ผู้ที่ทราบรหัส VDA จะสามารถสั่งสินค้าแทนร้านค้าได้
> หากร้านค้ายังไม่มีบัญชี โปรดแจ้งผู้ดูแลระบบเพื่อดำเนินการเปิดให้

### เซลล์และผู้ดูแลระบบ — ใช้บัญชี Microsoft ขององค์กร

เลือก "เซลล์ / Admin" แล้วเข้าสู่ระบบด้วยอีเมลของบริษัท ไม่ต้องกำหนดรหัสผ่านแยกต่างหาก

สิทธิ์ในการเข้าถึงข้อมูลคลังแต่ละแห่ง **กำหนดจากข้อมูลกลางขององค์กร** ไม่ได้ตั้งค่าในระบบนี้
หากเข้าสู่ระบบได้แต่ไม่พบคำสั่งซื้อ โปรดดู [ปัญหาที่พบบ่อย](#เซลล์เข้าสู่ระบบได้แต่ไม่พบคำสั่งซื้อ)

### อายุของ session

ระบบจดจำการเข้าสู่ระบบไว้ **7 วัน** หากหมดอายุระหว่างการใช้งาน ระบบจะนำผู้ใช้กลับไปยัง
หน้าเข้าสู่ระบบพร้อมข้อความแจ้ง กรณีนี้ไม่ใช่ความผิดปกติของระบบ เพียงเข้าสู่ระบบใหม่

## สำหรับคลัง VDA และร้านค้า

### หน้าสต็อก `/stock`

หน้าจอหลักที่ใช้งานประจำวัน แสดงสินค้าทุกรายการในคลังพร้อมข้อมูลประกอบการตัดสินใจสั่งซื้อ

| คอลัมน์ | ความหมาย |
|---|---|
| SKU | รหัสสินค้าและบาร์โค้ด (เรียงจากน้อยไปมากเป็นค่าเริ่มต้น) |
| สต็อก | จำนวนคงเหลือ แสดงเป็น "หีบ / เศษชิ้น" |
| ขายเฉลี่ย | ปริมาณขายเฉลี่ยต่อวัน คำนวณจากยอดขายจริง (7 วัน หากไม่มีข้อมูลจะใช้ 30 วัน) |
| CVD | จำนวนวันที่สินค้าคงเหลือเพียงพอต่อการขาย |
| MIN / MAX | เป้าหมายจำนวนวันที่ควรมีสินค้าคงคลัง |
| จำนวนสั่ง | ช่องกำหนดจำนวนที่ต้องการสั่ง (หน่วยหีบ) |
| หลังสั่ง | ค่า CVD หลังจากสินค้าที่สั่งเข้าคลังแล้ว พร้อมสถานะธงสี |
| ราคา / ส่วนลด / สุทธิ | ราคาตามตาราง C4 ณ วันปัจจุบัน |
| โปร | ขั้นโปรโมชันที่ได้รับ และของแถม |

**ตัวกรองด่วน**

| ชิป | แสดงสินค้าที่ |
|---|---|
| ทั้งหมด | ทุกรายการในคลัง |
| ควรสั่ง | สต็อกต่ำกว่าเกณฑ์ ระบบแนะนำให้สั่งเพิ่ม |
| สต็อกวิกฤต | **ของจะหมดก่อนของรอบใหม่มาถึง** — สั่งอย่างเดียวอาจไม่ทัน ควรหาทางเสริม เช่น ยืมจากคลังอื่นหรือเร่งซัพพลายเออร์ |
| สินค้าใหม่ | เพิ่งเข้าระบบ |
| ไม่ขาย 1 เดือน | ไม่มียอดขายเลยใน 30 วัน |
| ค้างสต็อก | ไม่ขาย 30 วันและยังมีของค้างอยู่ (เงินจม) |

> "สต็อกวิกฤต" เป็นชุดย่อยของ "ควรสั่ง" เสมอ — ถ้ารายการหนึ่งวิกฤต แปลว่าควรสั่งอยู่แล้ว
> แต่ที่ควรสั่งไม่ได้วิกฤตทุกตัว

**ความหมายของธงสี**

| สี | ความหมาย |
|---|---|
| 🟢 เขียว | จำนวนเหมาะสม |
| 🟡 เหลือง | เกินเป้าหมายเล็กน้อย อยู่ในเกณฑ์ที่ยอมรับได้ |
| 🔴 แดง | ควรตรวจสอบอีกครั้งก่อนส่งคำสั่งซื้อ |

> **ธงแดงไม่ได้ห้ามส่งคำสั่งซื้อ** เป็นเพียงการขอให้ยืนยันอีกครั้ง โดยเฉพาะกรณีสินค้าหมด
> หรือกรณีที่ 1 หีบเป็นจำนวนขั้นต่ำ ซึ่งเป็นสถานการณ์ปกติ ไม่ใช่ความผิดพลาด

**การดูยอดขายย้อนหลังรายสินค้า** ขยายแถวสินค้าเพื่อดูกราฟยอดขาย เลือกช่วงเวลาได้
7 / 30 / 90 วัน พร้อมค่าเฉลี่ยต่อวัน อัตราการเปลี่ยนแปลงเทียบสัปดาห์ก่อนหน้า (%)
และเส้นค่าเฉลี่ยเคลื่อนที่ 7 วัน

> ปุ่ม **90 วัน อาจแสดงเป็นสีเทาและเลือกไม่ได้** ในกรณีที่ข้อมูลจริงยังสะสมไม่ครบตามช่วงเวลา
> ระบบจะเปิดให้เลือกโดยอัตโนมัติเมื่อข้อมูลเพียงพอ ทั้งนี้เพื่อไม่ให้แสดงกราฟที่เติมค่าศูนย์
> จนอาจทำให้เข้าใจผิดว่ายอดขายลดลง

**สัญญาณเตือนข้อมูลไม่เป็นปัจจุบัน** โดยปกติมุมขวาบนจะแสดงข้อความ "ข้อมูล ณ <วันเวลา>"
เป็นตัวอักษรสีเทา หากเปลี่ยนเป็น **สีเหลืองหรือสีแดง** หมายความว่าข้อมูลไม่ได้รับการปรับปรุง
เป็นเวลานานผิดปกติ ค่า CVD และจำนวนที่ระบบแนะนำอาจไม่ตรงกับความเป็นจริง
ให้กดปุ่มรีเฟรช หากยังไม่เปลี่ยนแปลงโปรดแจ้งผู้ดูแลระบบ

### กด «ตรวจสอบคำสั่ง» แล้วมี 2 ขั้น

1. **ตรวจสินค้าที่มีโปรของแถม** (ขึ้นเมื่อมีสินค้าติดโปรของแถมในคำสั่ง) — ระบบเสนอปรับ
   จำนวนให้ลงขั้นโปร โดยปัดขึ้นเมื่อซื้อไปแล้วเกิน 30% ของขั้น (ขั้นที่ใหญ่กว่า 12 หีบ
   ใช้ 50%) ไม่ถึงเกณฑ์จะตัดเศษทิ้ง ทุกบรรทัดบอกจำนวนเดิมคู่กับจำนวนใหม่ และกด
   **«ใช้จำนวนเดิม»** เพื่อสั่งตามที่ตั้งไว้ได้เสมอ
2. **ยืนยันจำนวนที่สั่ง** — ตรวจว่าจำนวนเข้าเป้าหมาย MIN/MAX แก้ได้ในกล่องนี้เลย
   แล้วกด **ตรวจสอบคำสั่ง** เพื่อไปหน้า `/order`

### หน้าตรวจสอบก่อนส่ง `/order`

- **แก้ไขจำนวนและราคาได้ที่หน้านี้โดยตรง** ไม่ต้องย้อนกลับไปยังหน้าสต็อก
- ระบบแจ้งเตือนหากราคาแตกต่างจากราคาในระบบ (ส่งได้ แต่เซลล์จะเห็นสัญลักษณ์เตือน)
- ระบบแจ้งเตือนหากเคยสั่งสินค้ารายการเดียวกันภายใน 14 วัน
- สินค้าในกลุ่มโปรโมชันเดียวกันจะจัดเรียงติดกันพร้อมยอดรวมของกลุ่ม เพื่อให้เห็นว่าใกล้ถึงขั้นโปรโมชันหรือไม่

เลือก **ยืนยันส่ง** เพื่อส่งคำสั่งซื้อไปยังเซลล์เพื่อตรวจสอบ

> จำนวนที่ระบบแนะนำ **หักสินค้าที่อยู่ระหว่างจัดส่งแล้ว** คำสั่งซื้อที่ส่งไปก่อนหน้า
> และยังไม่ได้รับสินค้าจะไม่ทำให้ระบบแนะนำให้สั่งซ้ำ

### หน้าประวัติ `/history`

- **การแจ้งเตือนจากพนักงาน** ได้แก่ อนุมัติ ปฏิเสธ แก้ไขราคา แก้ไขจำนวน ออก PO ลบคำสั่งซื้อ
  รวมถึง **ยกเลิก PO** และ **รับสินค้าครบแล้ว**
- ข้อมูลสรุป 5 รายการ ได้แก่ คำสั่งซื้อทั้งหมด · รออนุมัติ · อนุมัติแล้ว · จำนวนหีบรวม · มูลค่ารวม
- กรองตามสถานะและช่วงเวลา (7 / 30 / 90 วัน)
- ขยายรายการเพื่อดู **ลำดับเหตุการณ์** (ส่ง → อนุมัติ → ออก PO) ราคาต่อบรรทัด
  และ **ของแถมที่พึงได้รับ**
- **สั่งซ้ำ** นำจำนวนเดิมกลับไปกำหนดที่หน้าสต็อก
- **ยกเลิกคำสั่งซื้อ** ทำได้เฉพาะรายการที่พนักงานยังไม่ได้ดำเนินการ (ยังไม่อนุมัติและยังไม่ออก PO)

### หน้าตั้งค่า `/manage`

กำหนดค่า MIN/MAX ตามกลุ่มสินค้า และแจ้ง **"หยุดสั่ง"** สำหรับสินค้าที่ไม่ต้องการให้ระบบ
แนะนำอีกต่อไป

## สำหรับเซลล์

### หน้าภาพรวม `/sales`

หน้าจอแรกหลังเข้าสู่ระบบ แสดงสถานการณ์ภาพรวมก่อนเริ่มปฏิบัติงาน

| การ์ดข้อมูล | ความหมาย |
|---|---|
| ออเดอร์รอตรวจ | จำนวนคำสั่งซื้อที่รอการตรวจสอบ เลือกเพื่อเข้าสู่หน้าตรวจสอบได้ทันที |
| มีราคาไม่ตรงระบบ | คำสั่งซื้อที่มีบรรทัดซึ่งราคาต่างจากระบบ ควรตรวจสอบก่อน (ร้านค้ากำหนดมาเอง หรือพนักงานขายแก้ในหน้าตรวจสอบก็นับ) |
| อัตราอนุมัติ (30 วัน) | สัดส่วนการอนุมัติจากคำสั่งซื้อที่ตัดสินแล้ว |
| ตัดสินแล้ว (30 วัน) | จำนวนคำสั่งซื้อที่ดำเนินการเสร็จสิ้น |

ส่วนด้านล่างแสดง **ร้านค้าที่ติดธงแดงมากที่สุด** ซึ่งควรติดต่อสอบถาม และ **รายการที่ตัดสินล่าสุด**

> อัตราการอนุมัติ **ไม่รวมคำสั่งซื้อที่ร้านค้ายกเลิกเอง** เนื่องจากคำสั่งซื้อที่ร้านค้ายกเลิก
> จะถูกลบออกจากระบบ จึงไม่เคยถูกนับรวมตั้งแต่ต้น

### หน้าตรวจสอบคำสั่งซื้อ `/sales/orders`

ด้านซ้ายแสดงรายการคำสั่งซื้อ ด้านขวาแสดงรายละเอียด

**การตรวจสอบทีละรายการ** ปรับจำนวนและราคารายบรรทัด → จัดกลุ่ม PO หากต้องแบ่งใบ → อนุมัติ

- **การปรับจำนวน** ใช้ปุ่ม − / + หรือพิมพ์ตัวเลขในช่องแล้วกด Enter
- **การกำหนดจำนวนเป็น 0 หมายถึงการตัดรายการนั้นออก** จากใบสั่งซื้อ ตัวเลขจะแสดงเป็นสีแดง
- ร้านค้าจะได้รับการแจ้งเตือนทุกครั้งที่มีการแก้ไขจำนวนหรือราคา

> ⚠️ **สินค้าที่อยู่ในกลุ่มโปรโมชัน** หากกำหนดจำนวนเป็น 0 รายการจะยังคงปรากฏในเอกสาร PO
> พร้อมหมายเหตุ เนื่องจากการนำออกจะทำให้ส่วนลดของสินค้ารายการอื่นในกลุ่มคลาดเคลื่อน
> กรุณาตรวจสอบขั้นโปรโมชันอีกครั้งก่อนส่ง

**การอนุมัติหลายรายการพร้อมกัน** เลือกคำสั่งซื้อหลายรายการ หรือใช้ปุ่ม
**"เลือกทั้งหมดที่ไม่มีธงแดง"** แล้วอนุมัติ ระบบจะดำเนินการทีละรายการตามลำดับ
พร้อมสรุปผลว่ารายการใดสำเร็จและรายการใดไม่สำเร็จพร้อมสาเหตุ

> คำสั่งซื้อที่การแบ่ง PO ไม่ผ่านเงื่อนไข เช่น กลุ่มโปรโมชันถูกแยกคนละใบ จะไม่สามารถเลือกได้

> หากผู้ใช้งานท่านอื่นอนุมัติคำสั่งซื้อรายการเดียวกันพร้อมกัน **ระบบจะบันทึกให้สำเร็จเพียงรายเดียว**
> อีกฝ่ายจะได้รับข้อความแจ้งว่าคำสั่งซื้อถูกตัดสินไปแล้ว กรณีนี้ไม่ใช่ข้อผิดพลาด
> แต่เป็นกลไกป้องกันการออกเลขที่ PO ซ้ำซ้อน

### หน้าใบสั่งซื้อ `/sales/po`

- ค้นหาด้วยเลขที่ PO รหัสคลัง หรือชื่อร้านค้า (ค้นหาจากข้อมูลทั้งหมด ไม่จำกัดเฉพาะหน้าที่แสดงอยู่)
- กรองตามช่วงวันที่ · คลัง · ประเภทราคา · **สถานะ**
- เลือกแถวเพื่อดูรายการในใบนั้น พร้อมปุ่ม **พิมพ์**
- เปลี่ยนสถานะได้จากตารางโดยตรง ตามลำดับ ออกแล้ว → ส่งซัพแล้ว → รับของแล้ว / ยกเลิก
- เลือกหลายใบเพื่อ **ดาวน์โหลดไฟล์ Excel รวมเป็นไฟล์เดียว** (ประกอบด้วยชีตสรุปและชีตรายใบ)

> **การเปลี่ยนสถานะมีผลต่อร้านค้าทันที** เมื่อกำหนดสถานะเป็น "ยกเลิก" หรือ "รับของแล้ว"
> ร้านค้าจะได้รับการแจ้งเตือน และระบบจะหยุดกันไม่ให้ร้านค้าสั่งสินค้ารายการนั้นซ้ำ
> (ก่อนหน้านี้ร้านค้าไม่ได้รับแจ้งเมื่อ PO ถูกยกเลิก และไม่สามารถสั่งสินค้าใหม่ได้เป็นเวลา 3 วัน)

### หน้าโปรโมชั่น `/sales/promotions`

ดูโปร C4 ของเดือนปัจจุบัน **แยกตามคลัง** — เลือกคลังจากรายการด้านบน หรือดูรวมทุกคลัง

> โปรของแต่ละคลังไม่เหมือนกัน เพราะผูกกับภูมิภาคของคลังนั้น การเลือกคลังก่อนดู
> จึงสำคัญ ไม่งั้นอาจแจ้งร้านด้วยโปรที่คลังนั้นไม่ได้รับจริง

ท่านจะเห็นเฉพาะคลังที่ตัวเองดูแล ส่วนผู้ดูแลระบบเลือกดูได้ทุกคลังที่
`/admin/promotions/c4`

### หน้าแจ้งเตือน `/sales/notifications`

- **คำสั่งซื้อจากร้านค้า** ทั้งรายการที่ส่งใหม่และรายการที่ร้านค้ายกเลิกเอง
  (ระบบบันทึกการรับทราบให้อัตโนมัติเมื่อเปิดดู)
- **รายการหยุดสั่ง** ร้านค้าแจ้งสินค้าที่ไม่ต้องการแล้ว (ต้องกดรับทราบด้วยตนเอง)

## สำหรับผู้ดูแลระบบ

เมนูแบ่งเป็น 5 หมวด เมื่อเข้า `/admin` ระบบจะนำไปยังหมวดแรกโดยอัตโนมัติ

| หมวด | หน้า | หน้าที่ |
|---|---|---|
| **ข้อมูล** | `/admin/data/sync` | สั่งดึงข้อมูลจาก Fabric และตรวจสอบสถานะรอบล่าสุด (จำนวนแถว ขนาด อายุข้อมูล ข้อผิดพลาด) |
| | `/admin/data/raw` | เปิดดูไฟล์และตารางที่ sync มาในรูปแบบดิบ |
| | `/admin/data/warehouses` | **ทะเบียนคลัง VDA** เพิ่มและแก้ไขคลังพร้อมรหัสลูกค้า |
| **ร้านค้า** | `/admin/stores/accounts` | **จัดการบัญชีร้านค้า** อนุมัติคำขอและรีเซ็ตรหัสผ่าน |
| | `/admin/stores/thresholds` | กำหนดค่า MIN/MAX ระดับกลุ่ม และรายการหยุดสั่ง |
| **โปรโมชั่น** | `/admin/promotions/c4` | ตรวจสอบโปร C4 ของเดือนปัจจุบัน **เลือกดูรายคลังได้** |
| **มุมมองทดสอบ** | `/admin/preview/vda` | เข้าดูระบบในมุมมองของคลัง VDA |
| | `/admin/preview/sales` | เข้าดูระบบในมุมมองของเซลล์ท่านอื่น |
| **ระบบ** | `/admin/system/admins` | จัดการรายชื่อผู้ดูแลระบบ |
| | `/admin/system/vda-sales` | ตรวจสอบว่าเซลล์แต่ละท่านดูแลคลัง VDA ใดบ้าง |

> ลิงก์รูปแบบเดิมที่บันทึกไว้ เช่น `/admin/sync` `/admin/vda` `/admin/stores`
> ยังคงใช้งานได้ ระบบจะนำไปยังหน้าใหม่โดยอัตโนมัติ

### การเปิดบัญชีให้ร้านค้าใหม่

1. ร้านค้ากรอกอีเมลที่หน้าเข้าสู่ระบบและเลือก VDA ของตน ระบบจะสร้างคำขอสถานะ "รอยืนยัน"
2. ผู้ดูแลระบบเข้า `/admin/stores/accounts` เพื่ออนุมัติคำขอ
3. ร้านค้าเข้าสู่ระบบอีกครั้ง ระบบจะให้กำหนดรหัสผ่านครั้งแรก (อย่างน้อย 8 ตัวอักษร)

### การเพิ่มคลัง VDA ใหม่

ดำเนินการที่ `/admin/data/warehouses` โดยเพิ่มรหัสคลังและรหัสลูกค้าผ่านหน้าจอได้โดยตรง
**ไม่ต้องแก้ไขไฟล์ตั้งค่าบนเซิร์ฟเวอร์** ค่าที่กำหนดไว้ใน `.env` ใช้เป็นค่าตั้งต้นครั้งแรกเท่านั้น
หากข้อมูลไม่ตรงกัน ระบบจะยึดข้อมูลที่บันทึกไว้ในฐานข้อมูล

### การเข้าดูข้อมูลร้านค้าโดยไม่ต้องทราบรหัสผ่าน

ดำเนินการที่ `/admin/preview/vda` โดยเลือกรหัส VDA ที่ต้องการ ฟังก์ชันนี้**สงวนไว้สำหรับ
ผู้ดูแลระบบเท่านั้น** ผู้ใช้อื่นไม่สามารถเรียกใช้ได้ ออกจากโหมดนี้ได้ด้วยปุ่มบนแถบด้านบน

### สัญลักษณ์แจ้งเตือนบนเมนู

จุดสีแดงบนเมนูหมายถึงมีรายการที่ต้องตรวจสอบ

| ตำแหน่ง | ความหมาย | การดำเนินการ |
|---|---|---|
| ข้อมูล → Sync | รอบดึงข้อมูลล่าสุดล้มเหลว | ตรวจสอบสาเหตุแล้วสั่งดึงใหม่ หากล้มเหลวซ้ำโปรดแจ้งทีมที่ดูแล Fabric |
| ร้านค้า → บัญชีร้านค้า | มีคำขอเปิดบัญชีรอการยืนยัน | เข้าไปดำเนินการอนุมัติ |
| โปรโมชั่น → โปร C4 | ข้อมูลโปรโมชันของเดือนปัจจุบันยังไม่พร้อม | ตรวจสอบว่าไฟล์โปรโมชัน sync มาครบถ้วนหรือไม่ |

## ปัญหาที่พบบ่อย

### เข้าสู่ระบบไม่ได้ ระบบแสดงข้อความ "รอผู้ดูแลยืนยันสิทธิ"

คำขอถูกส่งเรียบร้อยแล้ว อยู่ระหว่างรอผู้ดูแลระบบอนุมัติที่ `/admin/stores/accounts`
โปรดติดต่อผู้ดูแลระบบเพื่อเร่งดำเนินการ

### กรอกรหัสผ่านผิดหลายครั้ง ระบบแสดงข้อความ "พยายามบ่อยเกินไป"

ระบบมีกลไกป้องกันการคาดเดารหัสผ่าน กรุณารอตามระยะเวลาที่ระบบแจ้งแล้วลองใหม่
หากไม่สามารถระบุรหัสผ่านได้ โปรดขอรีเซ็ตรหัสผ่านและแจ้งผู้ดูแลระบบ

### ระบบนำกลับไปยังหน้าเข้าสู่ระบบเอง

session หมดอายุตามกำหนด 7 วัน สามารถเข้าสู่ระบบใหม่ได้ทันที ข้อมูลที่ส่งไปแล้วไม่สูญหาย

### ข้อมูลบนหน้าจอไม่เป็นปัจจุบัน

1. เลือกปุ่ม **"ตรวจข้อมูลใหม่"** ที่มุมขวาบนของหน้าสต็อก
2. ตรวจสอบข้อความ "ข้อมูล ณ" หากแสดงเป็นสีเหลืองหรือสีแดง หมายถึงระบบดึงข้อมูลไม่สำเร็จ
   โปรดแจ้งผู้ดูแลระบบ
3. ผู้ดูแลระบบสามารถสั่งดึงข้อมูลใหม่ได้ที่ `/admin/data/sync`

### หน้าจอแสดงข้อความ "เกิดข้อผิดพลาด" พร้อมรหัสอ้างอิง

**กรุณาบันทึกภาพหน้าจอให้เห็นรหัสอ้างอิงดังกล่าว** แล้วส่งให้ทีมพัฒนา เนื่องจากรหัสนี้
ใช้ตรวจสอบสาเหตุใน log ได้โดยตรง ทั้งนี้สามารถเลือก "ลองใหม่" ก่อนได้
เนื่องจากบางกรณีเป็นปัญหาชั่วคราว

### เลือก "ยืนยันส่ง" ไม่ได้

ปุ่มจะไม่สามารถใช้งานได้**เฉพาะกรณี**ที่ยังไม่ได้ระบุจำนวนสินค้าใด ๆ (ทุกรายการเป็น 0)

ธงแดงไม่ได้ห้ามส่งคำสั่งซื้อ ระบบจะแสดงกล่องข้อความให้ยืนยันแทน
หากพบว่าปุ่มไม่สามารถใช้งานได้ทั้งที่ระบุจำนวนแล้ว **กรณีนี้ถือเป็นข้อผิดพลาดของระบบ**
โปรดแจ้งทีมพัฒนาพร้อมภาพหน้าจอ

### เซลล์เข้าสู่ระบบได้แต่ไม่พบคำสั่งซื้อ

สิทธิ์การเข้าถึงมาจากข้อมูลกลางขององค์กร ไม่ใช่การตั้งค่าในระบบนี้ โปรดตรวจสอบตามลำดับ

1. อีเมลของท่านอยู่ในทะเบียนพนักงานขายหรือไม่
2. รหัสพนักงานขายของท่านผูกกับคลัง VDA ใดบ้าง
3. หากท่านถือหลายรหัส ให้เลือกปุ่ม **"ทุก VDA ของฉัน"** หรือสลับรหัสที่ใช้งานอยู่

ระบบจะแสดงแถบข้อความ "รหัสนี้ไม่มี VDA ที่ดูแล" หากเป็นกรณีที่ 2 โปรดแจ้งผู้ดูแลระบบ

### จำนวนของแถมในรายงานสูงผิดปกติ

อาจเกิดจากการนับของแถมของกลุ่มโปรโมชันซ้ำซ้อน โปรดแจ้งทีมพัฒนาพร้อมเลขที่คำสั่งซื้อ
(ของแถมของกลุ่มโปรโมชันเป็นสิทธิ์ของทั้งกลุ่ม ไม่ใช่ของแต่ละรายการ ซึ่งระบบมีกลไกป้องกัน
การนับซ้ำอยู่แล้ว)

### เปิดดูเอกสาร PO ไม่ได้

ระบบจะประกอบเอกสารขึ้นใหม่จากฐานข้อมูลโดยอัตโนมัติเมื่อไฟล์ต้นฉบับไม่พบ
หากยังไม่สามารถเปิดได้ โปรดแจ้งทีมพัฒนาพร้อมเลขที่ PO

## คำศัพท์ที่ควรทราบ

| คำศัพท์ | ความหมาย |
|---|---|
| **VDA** | คลังสินค้าที่บริหารจัดการสต็อกด้วยตนเอง (Vendor Distribution Agent) |
| **CVD** | Cover Days — จำนวนวันที่สินค้าคงเหลือเพียงพอต่อการขาย |
| **MIN / MAX** | เป้าหมายจำนวนวันที่ควรมีสินค้าคงคลัง (ค่าต่ำสุดและค่าสูงสุด) |
| **หีบ** | หน่วยสั่งซื้อมาตรฐานของระบบ หน่วยชิ้นใช้แสดงเฉพาะเศษที่ไม่ครบหีบ |
| **C4** | ตารางราคาและโปรโมชันกลางขององค์กร |
| **โปรโมชันแบบกลุ่ม (pooled)** | โปรโมชันที่รวมยอดสินค้าหลาย SKU เข้าด้วยกัน ของแถมเป็นสิทธิ์ของทั้งกลุ่ม ไม่ใช่ของแต่ละรายการ |
| **PO** | ใบสั่งซื้อที่ออกให้ฝ่ายจัดซื้อหลังจากเซลล์อนุมัติ |
| **ธงราคา** | สัญลักษณ์แสดงว่าราคาบนบรรทัดนั้นแตกต่างจากราคากลาง C4 (ป้าย "ราคาต่างระบบ") |
| **sync** | การดึงข้อมูลสินค้า ราคา และยอดขายจากระบบกลาง ดำเนินการอัตโนมัติทุกคืนเวลา 03:30 น. |
