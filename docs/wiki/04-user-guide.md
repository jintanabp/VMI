# 04 — คู่มือผู้ใช้

## สำหรับคลัง VDA / ร้านค้า

### หน้าสต็อก `/stock`

หน้าหลักที่ใช้ทุกวัน แสดงสินค้าทุกตัวในคลัง

| คอลัมน์ | ความหมาย |
|---|---|
| SKU | รหัสสินค้า + บาร์โค้ด (เรียงจากน้อยไปมากเป็นค่าเริ่มต้น) |
| สต็อก | คงเหลือ "หีบ / เศษชิ้น" |
| ขายเฉลี่ย | ต่อวัน จากยอดขายจริง (7 วัน ถ้าไม่มีใช้ 30 วัน) |
| CVD | ของที่มีพอขายกี่วัน |
| MIN / MAX | เป้าหมายจำนวนวันที่ควรมีของ |
| จำนวนสั่ง | ช่องปรับจำนวน (หน่วยหีบ) |
| หลังสั่ง | CVD หลังจากของเข้าแล้ว พร้อมธงสี |
| ราคา / ส่วนลด / สุทธิ | ราคา C4 ณ วันนี้ |
| โปร | ขั้นโปรที่ได้ และของแถม |

**ตัวกรองด่วน** — ทั้งหมด · ควรสั่ง · สต็อกวิกฤต · สินค้าใหม่ · ไม่ขาย 1 เดือน

**ธงสี** เขียว = จำนวนเหมาะสม · เหลือง = เกินเป้าหมายเล็กน้อย · แดง = ควรตรวจก่อนส่ง

> ธงแดง**ไม่ได้ห้ามส่ง** แค่ให้ยืนยันอีกครั้ง — โดยเฉพาะกรณี "ของหมด" หรือ "1 หีบคือขั้นต่ำ"
> ซึ่งเป็นเรื่องปกติ ไม่ใช่ความผิดพลาด

### หน้าตรวจก่อนส่ง `/order`

- **แก้จำนวนและราคาได้ที่หน้านี้เลย** ไม่ต้องย้อนกลับหน้าสต็อก
- เตือนถ้าราคาต่างจากระบบ (ส่งได้ แต่เซลล์จะเห็นธง)
- เตือนถ้าเคยสั่งสินค้าตัวเดียวกันใน 14 วัน
- สินค้าในกลุ่มโปรเดียวกันจะถูกจัดเรียงติดกันพร้อมยอดรวมของกลุ่ม

กด **ยืนยันส่ง** → ออเดอร์ไปรอเซลล์ตรวจ

### หน้าประวัติ `/history`

- แจ้งเตือนจากพนักงาน (อนุมัติ ปฏิเสธ แก้ราคา แก้จำนวน ออก PO ลบออเดอร์)
- สรุป 5 ช่อง: ออเดอร์ทั้งหมด · รออนุมัติ · อนุมัติแล้ว · รวมหีบ · มูลค่ารวม
- กรองตามสถานะและช่วงเวลา (7 / 30 / 90 วัน)
- กางออเดอร์ดู **timeline** (ส่ง → อนุมัติ → ออก PO), ราคาต่อบรรทัด และ **ของแถมที่ควรได้**
- **สั่งซ้ำ** — ดึงจำนวนเดิมกลับไปตั้งที่หน้าสต็อก
- **ยกเลิกออเดอร์** — ได้เฉพาะใบที่พนักงานยังไม่แตะ

### หน้าตั้งค่า `/manage`

ตั้ง MIN/MAX ต่อกลุ่มสินค้า และแจ้ง "หยุดสั่ง" สินค้าที่ไม่ต้องการให้ระบบแนะนำอีก

## สำหรับเซลล์

### ตรวจออเดอร์ `/sales/orders`

ซ้าย = รายการออเดอร์ · ขวา = รายละเอียด

**ทีละใบ:** ปรับจำนวน/ราคารายบรรทัด → จัดกลุ่ม PO ถ้าต้องแบ่ง → กดอนุมัติ

**หลายใบรวดเดียว:** ติ๊กหลายออเดอร์ หรือกด **"เลือกทั้งหมดที่ไม่มีธงแดง"** → อนุมัติ
ระบบทำทีละใบตามลำดับแล้วสรุปผลว่าใบไหนสำเร็จ ใบไหนไม่สำเร็จเพราะอะไร

> ออเดอร์ที่แบ่ง PO ไม่ผ่าน (เช่น กลุ่มโปรถูกแยกคนละใบ) จะติ๊กเลือกไม่ได้

### ใบสั่งซื้อ `/sales/po`

- ค้นหาด้วยเลข PO / รหัสคลัง / ชื่อร้าน (ค้นทุกหน้า ไม่ใช่แค่ที่โหลดมา)
- กรองตามช่วงวันที่ · คลัง · ประเภทราคา · **สถานะ**
- คลิกแถวเพื่อดูรายการในใบนั้น พร้อมปุ่ม **พิมพ์**
- เปลี่ยนสถานะได้จากตารางเลย: ออกแล้ว → ส่งซัพแล้ว → รับของแล้ว / ยกเลิก
- ติ๊กหลายใบแล้ว **ดาวน์โหลด Excel รวมไฟล์เดียว** (ชีตสรุป + ชีตต่อใบ)

### แจ้งเตือน `/sales/notifications`

- **ออเดอร์จากร้าน** — ร้านส่งใหม่ หรือยกเลิกเอง (รับทราบให้อัตโนมัติเมื่อเปิดดู)
- **รายการหยุดสั่ง** — ร้านแจ้งว่าสินค้าตัวไหนไม่ต้องการแล้ว (ต้องกดรับทราบเอง)

## สำหรับ Admin

`/admin` มี

| หน้า | ใช้ทำอะไร |
|---|---|
| `/admin/sync` | สั่งดึงข้อมูล Fabric และดูสถานะรอบล่าสุด |
| `/admin/vda` | ดูระบบในมุมของคลัง VDA |
| `/admin/sales` | ดูระบบในมุมของเซลล์คนอื่น |
| `/admin/stores` | จัดการบัญชีร้านค้า |
| `/admin/thresholds` | ตั้ง MIN/MAX ระดับกลุ่ม |
| `/admin/settings` | จัดการรายชื่อ admin |
