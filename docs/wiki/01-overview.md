# 01 — ภาพรวมโปรเจกต์

## ปัญหาที่ระบบนี้แก้

คลัง VDA ต้องสั่งสินค้าเข้ามาเติมเองทุกสัปดาห์ เดิมใช้ประสบการณ์ล้วน ๆ ทำให้

- สินค้าขายดี**ขาด** เพราะสั่งไม่ทัน
- สินค้าขายช้า**ค้างสต็อก** เพราะสั่งเผื่อมากเกิน
- ไม่รู้ว่าตัวไหนติดโปรอยู่ สั่งไม่ถึงขั้นเลยพลาดส่วนลด/ของแถม
- เซลล์ตรวจออเดอร์จากไฟล์ Excel ที่ส่งกันไปมา ไม่มีหลักฐานว่าใครแก้อะไร

ระบบนี้ดึงยอดขายจริงจาก Microsoft Fabric มาคำนวณว่า**ควรสั่งเท่าไร** แล้วส่งให้เซลล์อนุมัติ
พร้อมออกเลข PO และเก็บหลักฐานราคา/โปรไว้ทั้งหมด

## ผู้ใช้ 3 กลุ่ม

### 1. คลัง VDA / ร้านค้า
เข้าที่ `/stock` เห็นสินค้าทุกตัวพร้อม

- **สต็อกคงเหลือ** (หน่วยหีบ + เศษชิ้น)
- **ขายเฉลี่ยต่อวัน** จากยอดขายจริง 7 หรือ 30 วัน
- **CVD** (Cover Days) = ของที่มีพอขายกี่วัน
- **จำนวนแนะนำสั่ง** คำนวณให้อัตโนมัติ
- **ราคาและโปรโมชัน C4** ณ วันนั้น

เลือกสินค้า ปรับจำนวน แล้วกดส่ง → ออเดอร์ไปรอเซลล์อนุมัติ

### 2. เซลล์
เข้าด้วยบัญชี Microsoft ขององค์กร เห็นเฉพาะคลังที่ตัวเองดูแล (สิทธิ์มาจาก Fabric ไม่ใช่ allowlist)

- ตรวจออเดอร์ทีละใบ หรือ**อนุมัติหลายใบรวดเดียว**
- แก้จำนวน/ราคาได้ พร้อมบันทึกว่าใครแก้เมื่อไร
- อนุมัติแล้วระบบออกเลข PO ให้ และแบ่งใบอัตโนมัติถ้าราคาไม่ตรง C4
- ติดตามสถานะ PO ที่ `/sales/po`

### 3. Admin
`/admin` — ทดสอบมุมมองของ VDA/เซลล์คนอื่น, สั่ง sync Fabric, จัดการบัญชีร้านและ admin

## Tech Stack

| ชั้น | เทคโนโลยี |
|---|---|
| Framework | Next.js 15 (App Router) + React 19 + TypeScript 5.8 |
| UI | Tailwind CSS 4 + คอมโพเนนต์สไตล์ shadcn ใน `components/ui` |
| State / ข้อมูลฝั่ง client | TanStack Query 5 · TanStack Virtual (ตารางสต็อกยาว) |
| DB | Prisma 6 + SQLite (`prisma/dev.db`) |
| ข้อมูล master | Microsoft Fabric / OneLake → CSV cache ที่ `data/cache/` |
| Auth | Microsoft Entra ID (OAuth ฝั่ง server) + cookie session สำหรับร้าน |
| Export | ExcelJS |
| เทสต์ | Vitest (เฉพาะ logic ล้วน) |

## สิ่งที่ควรรู้ก่อนแก้โค้ด

1. **หน่วยเป็น "หีบ" เสมอ** — จำนวนชิ้นใช้แค่แสดงเศษที่ไม่ครบหีบ
2. **ราคาและโปรถูกแช่ไว้ตอนร้านกดส่ง** ห้ามคำนวณใหม่ตอนอ่าน เพราะแคมเปญเปลี่ยนทุกวัน
3. **basePath คือ `/vmi`** ใช้ helper `appPath()` เสมอเวลาต่อ URL
4. **หยุด `npm run dev` ก่อน `npm run build`** — ใช้โฟลเดอร์ `.next/` ร่วมกัน
